# ESP32-C6 + DFRobot AS3935 Lightning Sensor + Home Assistant MQTT

Firmware for DFRobot AS3935 Lightning Sensor running on ESP32-C6 with Home Assistant MQTT integration support.

It provides real-time lightning detection, configurable noise filtering, and event-based MQTT communication.

## Features

- Lightning detection (distance + energy estimation)
- Disturber detection filtering
- Configurable sensor parameters via MQTT
- Home Assistant MQTT auto-discovery
- Event-based messaging (lightning, disturber, noise)

## Hardware

- ESP32-C6
- DFRobot AS3935 Lightning Sensor
